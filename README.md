# NOX Corporate Site

GitHub Pagesで公開できる静的な企業サイトです。

## ページ構成

- `index.html` — トップページ
- `services.html` — サービス
- `insights.html` — 導入事例・コラム
- `company.html` — 会社情報
- `contact.html` — お問い合わせ
- `privacy.html` — プライバシーポリシー
- `assets/` — 共通CSS・JavaScript

## GitHubへのアップロード

リポジトリ直下へ、HTMLファイル6点、`assets`フォルダ、READMEを同じ構成のままアップロードしてください。

GitHub Pagesは、`main`ブランチの `/(root)` を公開元に設定します。

## 正式公開前に必要な更新

- `company.html` の所在地と代表者
- `privacy.html` の制定日および法的内容
- `contact.html` のフォーム送信先
- 実在する導入事例・コラム内容への差し替え
